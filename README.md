# FACTOR LINKS｜公約数リンク

数字の公約数から6×6のラテン方陣を復元するスマートフォン向け数学ロジックパズルです。

- **各行・各列**：6種類の数字を1回ずつ配置（3×3ブロック制約はありません）。
- **実線**：両隣の数字の最大公約数が1。
- **点線**：両隣の数字の最大公約数が2以上。
- **60本の線すべてが手掛かり**：記号のない線を無視しません。

## Play

[GitHub Pages](https://yamiedrich49.github.io/FACTOR-LINKS/) ／ [単体HTMLソース](index.html)

スマホでブラウザを開くだけで動作します。ビルド・外部ライブラリは不要です。

## 問題品質の検証

```bash
node tools/audit.mjs
node tools/audit.mjs --json
```

Node.js 18以降、外部パッケージ不要。問題を追加・修正したら必ず実行してください。GitHub Actionsでも push / PR 時に検証します。

検証内容：
1. 6種類の正の整数、36マス、行・列の重複禁止、初期数字位置の妥当性
2. **縦横60本**の実線・点線が解答の公約数条件と一致するか
3. 候補制約伝播＋全探索による**一意解（解の数=1）**の証明
4. 仮置きなしの論理ソルバー（第1〜3階層）による未確定マス数の比較
5. 初期数字を1個ずつ外しても一意性が残るか（冗長性の手掛かり）

### 論理ソルバーの階層

- **Tier 1**：確定数字・行列の重複禁止・行列内唯一候補・確定数字に接する線
- **Tier 2**：両端が未確定でも線の候補組み合わせから削減（アーク整合性）
- **Tier 3**：行列のペア・トリプル制約まで

これは機械的な**必要推理の上限の目安**であり、子どもの実プレイ時間や面白さをそのまま測るものではありません。操作や手掛かりに気づくまでの時間、推理の転換点、同じ手順の繰り返しなどは、別途プレイテストで評価します。

## 制作方針

数学的に美しい、論理的に面白い、触って圧倒的に気持ちいい。

既存のルールを増やす前に、問題の質・導入の成長曲線・無駄のないUI・成功時の達成感を磨きます。
